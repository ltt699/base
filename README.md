# 模型知识库

个人投资/交易/分析知识管理系统。每个"模型"是一个独立 Markdown 文件，按体系分目录存放。

## 目录结构

```
knowledge-base/
├── README.md            ← 本文件：使用说明
├── INDEX.md             ← 总索引：所有模型的速查表
├── templates/
│   └── model-template.md ← 新增模型的标准模板
├── 01-value-investing/   ← 价值投资体系（M01-M06）
├── 02-futures-arbitrage/ ← 期货套利体系（M07-M09）
├── 03-trading-risk/      ← 交易与风控体系（M10-M12）
├── 04-technical/         ← 技术分析体系（M13）
├── 05-finance/           ← 财务分析体系（M14）
└── 06-data-analysis/     ← 数据分析体系（M15-M17）
```

## 编号规则

- `M01` ~ `M99`：全局唯一编号，一旦分配永不复用
- 文件名：`M{编号}-{模型名}.md`
- 分类目录放不下时新建 `{序号}-{体系名}/` 目录

## 如何新增一个模型

1. 复制 `templates/model-template.md`
2. 全局分配下一个编号（查 INDEX.md 的"下一个可用编号"）
3. 填写模板内容后放入对应体系目录
4. 更新 `INDEX.md` 表格（一行一条）
5. 如果新模型与已有模型有关联，双向更新双方的"关联模型"字段

**捷径**：直接把文章链接/内容丢给 CatPaw（catpaw-对内），说"入库"，我会自动完成以上全部步骤。

## 如何使用

- **查模型**：先看 `INDEX.md` 速查表，再点开具体文件
- **实战调用**：分析一家公司时，按 `01价值投资` → `05财务` 的顺序过一遍相关模型（六问、大坐标、报表质量）
- **复盘沉淀**：每次实际用到某模型产生了新体会，追加到该文件的"实战记录"区
- **定期回顾**：建议每季度扫一遍 INDEX，淘汰不用的、合并重复的
