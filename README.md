# 模型知识库

个人投资/交易/分析知识管理系统。每个"模型"是一个独立 Markdown 文件，按体系分目录存放。

## 目录结构

```
knowledge-base/
├── README.md            ← 本文件：使用说明
├── INDEX.md             ← 总索引：所有模型的速查表
├── ANALYSIS-LOG.md      ← 分析记录：可证伪判断存档 + 正确率统计
├── stats.py             ← 分析记录审计脚本（统计/校验/回写）
├── templates/
│   └── model-template.md ← 新增模型的标准模板
├── 01-value-investing/   ← 价值投资体系（M01-M06、M18、M19、M21-M24）
├── 02-futures-arbitrage/ ← 期货套利体系（M07-M09）
├── 03-trading-risk/      ← 交易与风控体系（M10-M12、M20）
├── 04-technical/         ← 技术分析体系（M13）
├── 05-finance/           ← 财务分析体系（M14、M25-M28）
└── 06-data-analysis/     ← 数据分析体系（M15-M17）
```

## 编号规则

- `M01` ~ `M99`：全局唯一编号，一旦分配永不复用
- 文件名：`M{编号}-{模型名}.md`
- 分类目录放不下时新建 `{序号}-{体系名}/` 目录

## 如何新增一个模型

1. 复制 `templates/model-template.md`
2. 全局分配下一个编号（查 INDEX.md 的"下一个可用编号"）
3. 填写模板内容后放入对应体系目录
4. 更新 `INDEX.md` 表格（一行一条）
5. 如果新模型与已有模型有关联，双向更新双方的"关联模型"字段

**捷径**：直接把文章链接/内容丢给 CatPaw（catpaw-对内），说"入库"，我会自动完成以上全部步骤。

## 如何使用

- **查模型**：先看 `INDEX.md` 速查表，再点开具体文件
- **实战调用**：分析一家公司时，按 `01价值投资` → `05财务` 的顺序过一遍相关模型（六问、大坐标、报表质量）
- **快速体检**：只想判断"这家公司赚的是不是真钱"，直接跑 `05-finance/M26` 的「快速体检清单（四问）」——①合同负债同比 ②应付周转天数 ③票据/应收结构 ④经营现金流÷核心利润，10 分钟出绿/黄/红。**背离时以现金为准**
- **复盘沉淀**：每次实际用到某模型产生了新体会，追加到该文件的"实战记录"区
- **验证回填**：记录到期后，在 `ANALYSIS-LOG.md` 对应条目的"验证记录"字段**追加**，不要覆盖原判断——保留当时的错误推理，才可能校准自己的偏差。回填格式：日期｜数据口径｜体检结果｜阶段性结论
- **定期回顾**：建议每季度扫一遍 INDEX，淘汰不用的、合并重复的

## 工具脚本

### stats.py — 分析记录质量审计

**为什么有这个脚本**：`ANALYSIS-LOG.md` 的质量依赖自觉，而自觉会衰减。三个具体诱因：

1. **口算不可靠**——2026-10-30 口头统计"5 条逆向、2 条顺向"，grep 核对实为 4 逆向 + 2 偏中性 + 1 顺向。人脑数文本必错，统计交给程序
2. **格式会腐化**——写脚本时发现 A005 措辞与其他记录不一致（"警告为" vs "本判断为"），会被统计静默漏项；跑通后又抓出 A004 缺验证哨/证伪条件
3. **判断会被遗忘**——每条都有验证期限，没有提醒就永远停在"⏳待验证"，系统退化成日记

**用法**：

```bash
python3 stats.py            # 打印统计（记录数/状态分布/逆向占比/置信度/到期提醒）
python3 stats.py --check    # 只做格式校验，缺五要素 exit 1（可挂 pre-commit hook）
python3 stats.py --update   # 回写顶部"正确率统计"表
python3 stats.py --file x.md # 指定其他记录文件
```

**五要素校验项**：置信度 / 当时共识 / 方向性预测 / 验证哨 / 证伪条件——缺一即报错。

**迭代规则（重要）**：脚本头部的 `【迭代规则】` 区块登记每次修改及原因，格式 `日期 | 改了什么 | 为什么改`。修改统计口径（如"逆向偏中性"是否计入逆向）时必须同时说明对历史数据的影响，否则跨期正确率不可比。
