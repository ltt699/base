## M20：投资组合管理原则

- **体系**：交易风控
- **来源**：盛京剑客《关于投资的十反对与十提倡》+ 语雀投资组合板块（《不可重仓的逻辑》《过分研究个股在逻辑上就是错的》《投资组合如何应对暴跌 70% 的行情》等 8 篇）
- **链接**：https://www.yuque.com/jiyuan-kbh1a/nkmevz/ddq7ti
- **一句话**：单股黑天鹅靠组合吸收——25 只均衡持仓下，单股回撤 45% 对组合影响 < 2%
- **标签**：`组合管理` `风控` `纪律`

### 核心内容

**十反对十提倡（2020-10-24 版精要）：**

| 反对 | 提倡 |
|:---|:---|
| 加杠杆/借钱炒股 | 闲钱+工资合理规划投资 |
| 重仓一只股 | 适度分散、组合投资 |
| 把股票当赌博筹码 | 抓住股权本质，以股东态度投资 |
| 频繁短炒 | 中长期持有优质公司，压缩摩擦成本 |
| 迷信分析有效性（买一只必须涨一只） | 依靠概率组合原理，不求全胜 |
| 以涨跌和情绪做决策 | 政经/行业/质地/估值综合理性决策 |
| 加群跟买迷信大V | 独立思考，盈亏找自己原因 |
| 刷论坛看公号代替系统学习 | 系统学习（证券从业/CFA-1 级别） |
| 招摇得瑟、财不露白反面 | 低调闷声发财 |
| 恨国党与悲观主义者入市 | 看好国运的乐观主义者入市 |

**量化案例（剑客实盘）：** 康美药业单股回撤 45%，但 25 只个股组合下，对组合总净值影响 < 2%——**不可重仓的数学逻辑：仓位 = 单股最大灾难的预算上限**。

**"过分研究个股在逻辑上就是错的"**：研究精力应按组合权重分配而非深度倾斜；组合层面追求的是概率与赔率的整体最优，不是单票的完美论证。

**组合应对极端行情（暴跌 70% 场景）**：靠的不是预测，是事前的分散结构 + 闲钱无杠杆 + 现金流持续补仓能力。

### 适用场景

- 任何股票组合的仓位结构设计（先定"单票最大亏损容忍度"再定仓位）
- 自查投资行为清单（十反对即十种作死模式）

### 不适用边界

- 期货套利组合（M07）的多组合分散是概率均值逻辑，与本模型的"个股黑天鹅吸收"逻辑同源但标的不同
- 极小资金（如 < 10 万）25 只组合操作成本过高，可降至 5-8 只
