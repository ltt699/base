## M16：文本挖掘全流程（Pipeline）

- **体系**：数据分析
- **来源**：苏格兰折耳喵系列博客（虎嗅 4W+ 文章文本挖掘案例、共享单车行业文本挖掘、欢乐颂2 舆情解读）
- **链接**：https://www.cnblogs.com/luoluo-123/
- **一句话**：从语料采集到洞察输出的标准化文本分析 pipeline
- **标签**：`文本挖掘` `NLP` `方法论`

### 核心内容

**标准 Pipeline（以虎嗅 4W+ 文章挖掘为范式）：**

```
数据采集（爬虫/API/RSS）
    ↓
数据预处理（去噪、去重、分词、停用词）
    ↓
文本建模（词频统计 / 词向量 / 主题模型 LDA / 聚类）
    ↓
可视化（词云 / 语义网络图 / 时间趋势）
    ↓
洞察输出（行业现状 → 趋势研判 → 行动建议）
```

**关键实战细节（博客案例沉淀）：**
- **数据采集类型全覆盖**：社媒数据（微博/微信）+ 电商评论 + 新闻资讯 + 专业社区，不同源口径需清洗对齐
- **外部数据思维（增长黑客视角）**：不只盯自有后台数据（UV/PV），社会化媒体上的用户自发讨论才是早期信号（"共享单车"行业拐点在社媒舆情中早于运营数据显现）
- **时间切片分析**：舆情热度的时间曲线（如《欢乐颂2》播放期话题结构演变）可将" caliente 事件"与"长尾话题"分离
- **微信运营闭环**：后台数据（图文阅读/分享/留言）优化定位与内容初始化——数据先指导选题，再验证传播
- **人的因素**：数据分析需要"搞"人——跨部门拿数据、向上汇报都要沟通术

### 适用场景

- 行业研究报告中的定性资料量化处理
- 新媒体运营/增长分析的内容选题与复盘
- 自媒体声量与品牌健康度追踪

### 不适用边界

- 中文分词与语料的领域适配是新领域最大的坑（须先用 M15 建领域词库）
- 文本挖掘结论是相关性，因果解释需业务判断介入

### 关联模型

- M15 舆情模型五步法：采集后的"关键词方案"环节
- M17 心理动力学：从描述性挖掘走向动机性洞察
