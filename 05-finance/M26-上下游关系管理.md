## M26：上下游关系管理分析（营运资金核心）

- **体系**：财务分析
- **来源**：张新民《财务报表分析》公开课第 32-41 节，B 站个人笔记整理
- **链接**：https://www.bilibili.com/read/cv17650295
- **一句话**：中小企业的分析核心就是"以存货或业务为核心的上下游关系管理"——流动比率会骗人，收付款结构不会
- **标签**：`财报` `营运资金` `上下游`

### 核心内容

**一、流动比率的两个结构性陷阱**

| 陷阱 | 案例 | 真相 |
|:---|:---|:---|
| 忽略流动资产结构 | 流动资产=其他应收款 2 亿，流动负债=短期借款 1 亿 → 比率 2:1 看似安全 | 其他应收款与经营无关，不是偿债能力 |
| 忽略流动负债结构 | 流动资产=存货 40 亿，流动负债=预收款项 100 亿 → 比率 1:2.5 看似危险 | 预收款是"货没发"而非"债要还"，毛利率 90% 下毫无压力 |

**结论**：营运资金分析必须看结构，不能只算比率。

**二、用"存货 × 固定资产"组合辨识行业特征**

| 组合 | 行业 |
|:---|:---|
| 大量存货 + 少量固定资产 | 贸易类公司、房地产开发 |
| 少量存货 + 大量固定资产 | 酒店、银行 |
| 大量存货 + 大量固定资产 | 钢铁、汽车制造 |
| 少量存货 + 少量固定资产 | 事务所、咨询机构 |

**三、收钱质量：应收账款周转率的 4 个公式缺陷**

1. 含增值税，税率变化而公式未变
2. 报表中应收账款是**净值**，公式应用**原值**
3. 未考虑**应收票据**（质量高于应收账款）
4. 未考虑**预收款项**（提前收的钱）

→ 正确做法：把「应收票据 + 应收账款 + 预收款项」作为一组系统观察销售款回收状况：
- 比较合计数年末与年初的变化（规模）
- 比较应收票据与应收账款的结构变化（质量：票据 > 账款）
- 观察是否"以减少预收款的方式促销"

**四、付钱策略：以存货为核心的付款管理**

- 核心不等式：**存货周转速度 ≫ 对供应商付账速度** → 差额即对供应商资金的占用
- 案例：存货 86 亿、负债 336 亿，差 250 亿 = 用供应商的钱支持自己的周转
- 「节约现金流出量，就是增加了现金流入量」

**五、格力电器案例（正例）的完整逻辑链**

```
收钱：应收票据高（债权质量高）+ 尽量不开商业汇票
付钱：应付账款高（占用供应商）
净效果：长期货币存量高 = 综合市场竞争地位决定的
代价：为冲销售目标，预收款减少、应收增加 → 回款放缓
```

**反例**：规模表明回款减少（债权少收 33 亿）、结构表明质量恶化（应收↑票据↓）。

**六、异常信号（人为调节流动比率）**
- 异常的流动资产虚减
- 异常的流动负债虚增
→ 流动比率被歪曲

**七、固定资产周转率**
- 分子分母都用**原值**：营业收入 / 平均固定资产原值
- 关键判断：固定资产净值增长是否带来营业收入增长（增长不带动收入 = 周转速度下降 = 资产低效）
- 两类低效原因：系统管理能力不高；结构设计与业务不匹配

**八、竞争质量的交叉验证（核心洞察）**

| 组合 | 判定 |
|:---|:---|
| 核心利润率高 + 经营资产报酬率低 | 市场能力强，但**经营资产结构失衡**（货币资金/在建工程/其他应收款过高，固定资产闲置） |
| 核心利润率低 + 经营资产报酬率高 | 周转型生意，赚辛苦钱 |

### 快速体检清单（四问）

> 本模型全部内容压缩成 4 个数，10 分钟跑完一家公司。**背离时以现金为准**——利润表可以修饰，现金流表难修饰，资产负债表是两者的裁判。

| # | 检查项 | 怎么算 | 绿灯 | 黄灯 | 红灯 |
|:--:|:---|:---|:---|:---|:---|
| ① | **合同负债同比** | 期末合同负债 ÷ 期初，同时看 合同负债/营收 | 增长，且占比 >10% | 持平或小幅下降 | 连续 2 年下滑 |
| ② | **应付周转天数** | 平均应付账款（含应付票据）÷ 营业成本 × 期间天数 | 稳定或小幅拉长，且 ≤120 天 | 大幅拉长（>30 天） | 持续缩短（对上游议价弱化） |
| ③ | **票据 / 应收结构** | （应收票据+应收款项融资）÷ 应收总额；再看 应收账款增速 vs 营收增速 | 票据占比上升，应收增速 < 营收增速 | 票据占比持平 | 票据占比下降 + 应收增速 ≫ 营收增速 |
| ④ | **经营现金流 ÷ 核心利润** | 经营活动现金流净额 ÷ M27 核心利润 | ≥1 | 0.8–1 | <1，且连续两年 |

**判定规则**

- **4 绿**：产业链强势位置成立，经营质量可托底估值
- **3 绿 1 黄**：成立但有边际松动。看是哪个黄——①② 黄是"需求/议价"问题，③④ 黄是"回款/质量"问题
- **出现任意 1 红**：进入"需解释"状态，必须找到具体原因（扩张备货？集采降价？渠道改革？原材料抢料？），找不到原因就当可疑账看
- **≥2 红**：必须再分两种形态，否则会误杀成长股、放过衰退股：
  - **(a) 营收停滞/下滑下的 ≥2 红 = 伪竞争力**。货卖不动了，钱还被上下游和存货吃掉，利润是靠占款撑出来的，反噬只是时间问题（实证：天坛生物，营收 -13.73% 而应收 +6.5%、存货继续增 234 亿）
  - **(b) 高增长下的 ≥2 红 = 扩张期占用**。用未来的增长抵押现金，本身不是造假，但**必须跟踪增量应收/存货能否在下一年转成营收**；转不成就退化为 (a)（实证：比亚迪，营收持平但应收 +52.61%、存货+应收合计增超千亿，对应海外销量翻倍）
  - 判据：看**营收增速的符号**。营收在涨 → 按 (b) 给观察期；营收在跌 → 按 (a) 直接降级

**四问的隐藏陷阱**

1. **④ 过了不代表安全**。经营现金流 > 核心利润可能来自三个完全不同的源头：
   - 折旧摊销大（重资产，健康）
   - 应付票据 / 应付账款暴增（占用供应商，**透支未来**）
   - 合同负债暴增（预收客户，最健康但依赖增长持续）

   → 所以 ④ 必须和 ①② 联读：**④ 绿 + ② 红 = 现金流是借来的**。
2. **② 的"绿灯"不等于好**。应付账款周转天数长期极低（<10 天）说明公司根本占不到上游的钱——这类公司（采浆、原料药、农产品加工）是被上游占用的一方，要看它是否用预付款/长单换稳定供应，而不是简单判为弱。
3. **② 的极端值（>300 天）要先拆表**。应付账款科目常混入设备款、工程款等**非经营性**应付款，会把周转天数算到失真（实证：济川药业，营业成本仅 7.34 亿而应付账款 8.27 亿，周转 372 天，明显不是药品辅料采购能做出来的数）。极端值出现时先确认是否含工程/设备款，再决定红黄。
4. **② 缩短也可能是主动做资产负债表清洁**。把占供应商的钱还掉、换成银行贷款，短期打击现金流，长期换信用与供应保障——这时的红是选择，不是弱化（实证：济川药业应付账款 11.97→8.27 亿，同期短期借款 6.96→10.86 亿）。区分方法：**看有息负债是否同步上升**。
5. **④ 要扣掉应付款项本身的贡献**，不能只看比值。算法：`OCF −（应付票据+应付账款 期末−期初）` 得到「经营性真实现金」，再除以核心利润。比亚迪 OCF 544.70 亿看着漂亮，但应付票据单期增 563.99 亿、应付账款减 140.37 亿、合计净增 423.62 亿 → 扣掉后只剩约 121 亿（实证中最刺眼的一条）。

**一键记录格式**（写进分析记录用）

```
① 合同负债 __亿（同比 __%，占营收 __%）
② 应付周转 __天（上年 __天）
③ 票据占比 __%（上年 __%）｜应收增速 __% vs 营收增速 __%
④ 经营现金流 __亿 ÷ 核心利润 __亿 = __
结论：__绿 __黄 __红 → 强势 / 中性 / 伪竞争力
```

### 适用场景

- 快消/制造/贸易类公司的经营质量诊断（尤其"看起来赚钱但不产生现金"的公司）
- 识别"用供应商的钱做生意"的真实竞争力 vs "靠预收款圈钱"的伪竞争力
- 判断促销是否以牺牲回款质量为代价

### 不适用边界

- 无存货的服务业/软件业，"以存货为核心的付款管理"不适用
- 预收款模式（白酒、教育、健身）需结合履约能力判断，不能只看负债规模

### 实战记录

- **2026-11-01｜四问首次跑通检验（2026 三季报，天坛生物/安琪酵母/济川药业/比亚迪）**
  - 四问对不同类型的公司都能拉开区分度：安琪 3绿1黄、济川 名义4绿、天坛 ≥2红、比亚迪 名义绿实质红
  - **本次验证修正了 3 条原始判据**：①≥2红要分“伪竞争力/扩张期占用”两形态（看营收增速符号）；②>300 天的周转要先拆非经营性应付款；③④ 要扣除应付款项本身的贡献再算
  - 最大收获：**④ 是四问里最容易被骗的一项**。比亚迪 ④ 名义 2.3–2.7、天坛 ④ 0.56，两家都有巨额折旧，单看比值会得出相反结论，必须扣应付款净增才能分清“折旧带来的真现金”和“占款借来的假现金”
