## M19：极简价值投资框架

- **体系**：价值投资
- **来源**：盛京剑客《简版价值投资总结》（雪球研讨第三版）+《价值投资是极简思维》（语雀"盛京剑客谈成功投资"知识库）
- **链接**：https://www.yuque.com/jiyuan-kbh1a/nkmevz/ga3zns
- **一句话**：整座价值投资大厦压缩成一句话——每股收益 × 估值 = 股价；公司用能力圈搞定，估值用安全边际搞定，竞争力用护城河+保护伞搞定
- **标签**：`价值投资` `极简框架` `总纲`

### 核心内容

**框架全貌：**

```
每股收益(E) 对应公司  → 用能力圈搞定
估值(PE)    对应市场  → 用安全边际搞定
持续竞争力            → 用护城河 + 保护伞搞定

E × 估值 = 股价；未来股价由公司和市场共同决定
```

**核心辩证关系（质地 ↔ 安全边际）：**
- 公司质地优 → 可适度降低安全边际要求
- 安全边际高 → 可适度放宽质地要求
- **质地优 + 边际高 = 完美投资**
- "好公司是最大的安全边际"与"安全边际抵过好公司"都有理——一因素强，另一因素可让步

**极简思维的纪律（来自《价值投资是极简思维》）：**
- 价值投资 = 极简思维：抓住"股权是公司所有权"这一个本质，其余皆是派生
- 判断股票只需回答三个问题：生意好不好（质地）、价格便不便宜（边际）、拿不拿得住（认知深度）
- 越简单越难执行——简单是"想透后的简单"，不是"没想过的简单"

### 适用场景

- 给初学者建立认知骨架（一个公式装下整个体系）
- 自检：分析一家公司时，四个要素（E/估值/护城河/保护伞）是否都有结论，缺哪个补哪个

### 不适用边界

- "保护伞"（政策壁垒、牌照、成本优势等外生性保护）与护城河的边界在强周期行业模糊
- 极简框架不告诉你 E 的具体增速怎么估——那是 M18（净资产视角）和 M02（六问）的任务

### 关联模型

- M05 P=PE×E：同一个公式的数学展开版（本框架是它的极简口语版）
- M18 长期投资四种钱：E/B 的内生来源
- M01 三个本质：投资本质=前瞻，与"能力圈搞定 E"互为表里
